# lsp-gpt

... let's use chatGPT as language server!

## what is it?

This project contains a language server (LS) that uses the chatGPT API in order
to provide suggestions according to the language server protocol (LSP).
Additionally it contains clients for Visual Studio Code and NeoVim.

# documentation

This project is a very bare-bones prototype showcasing the funtionality of
having suggestions in the editor, that are generated by invoking the API of
chatGPT.

LS implementation currently done in rust, since the library and examples are
extensive. Can be done in Java for the actual project, since code from the
plantUML project can be re-used more easily.

LS integration in Visual Studio Code requires a vsc extension. documentation
available here: 
https://code.visualstudio.com/api/language-extensions/language-server-extension-guide

```bash
cd clients/vscode/
npm install
# install vsce for extension creation
npm install -g @vscode/vsce
# generate .vsix extension file
vsce package
```

Alternatively, open Debug Session (`Ctrl` `Shift` `D`), select `Run lsp-gpt extension`
and a new window with the extension installed will open.


nvim integration is well documented: help lsp
- install lsp-gpt (in order to get it executable for the user): `cargo install --force --path .`
- run in nvim: `:lua vim.lsp.start({ name = 'lsp-gpt', cmd = { 'lsp-gpt' }, root_dir = vim.loop.cwd(), })`
